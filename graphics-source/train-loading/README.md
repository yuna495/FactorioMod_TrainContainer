# 列車隣接用 TrainContainer 素材

主要参照: リポジトリルートの `列車隣接コンテナデザイン.png`。
通常チェストの既存画像を加工せず、専用の形状・マテリアルから生成しています。

## ファイルと構造

- `train-loading.blend`: 編集用モデルと16個の透過レンダーシーン。
- `build.py`: モデル／シーンの再生成と全画像の出力。
- `preview.py`: Lua が返したレイヤー配置をそのまま画像化する目視検証用ツール。
- `preview.png`: 6／13／20マスの横・縦、およびゲーム倍率の比較。
- `../../graphics/entity/train-container/train-loading/`: ゲームが読む16枚のPNG。

`MODEL - editable module catalog` は13マスの組立例です。T6、J、L、R は
コレクションインスタンスで配置しています。元の各コレクションには部品名を付けた
編集可能なメッシュがあり、天板、リブ、ローラー、補強柱、警告帯、制御盤を分離しています。
参照画像は Blender ファイルにパックしています。

`wide-t6` / `wide-j` / `wide-l` / `wide-r` と対応する `high-*` が本体シーン、
`*-shadow` が投影影シーンです。カメラ・照明・出力先を各シーンに保存しています。
T6は6マス、Jは1マス、L/Rは両端内側へ重ねるカバーです。
荷役機構は左右両側にあります。静止した状態でも搬送設備と分かるようローラーを露出しています。

## 再出力

リポジトリルートで、Blender の実行ファイルを指定して実行します。

```text
blender --background --factory-startup --python graphics-source/train-loading/build.py
lua tests/train_loading_graphics.lua .verify-train-layers.tsv
python graphics-source/train-loading/preview.py .verify-train-layers.tsv
```

`build.py` は保存済みモデルとPNGを再生成します。Blender 上で手編集したモデルを
残す場合は別名保存してください。手編集後は該当本体シーンを直接レンダーできますが、
影は生成時のメッシュを投影したものなので、形状変更時には影も再生成する必要があります。
恒久的な調整は `build.py` に反映すると再現できます。

## 投影・実装

元モデルの1単位は1タイルです。45度の正投影を使い、シーン内のY座標だけ
sqrt(2)倍して縦方向の短縮を補正します。横・縦とも64pxで1タイルとなり、
Luaの `scale = 0.5` でゲーム上32pxです。縦向きは画像回転ではなく、
モデルを回転して同じ光源から再レンダーしています。

画像原点は地面中心です。透明余白を含むためLuaの追加シフト補正は不要です。
T6は横512×192／縦192×512、Jは192×192、端部は横160×192／縦192×160です。
影は照明方向へ実形状を地面投影した黒シルエットで、Lua側で不透明度35%を適用します。
静止した接地影であり、柔らかい影や他モジュールへの相互投影は表現しません。

`data.lua` で通常segmentに専用module定義を付加し、`scripts/sprite_generation.lua`
で長さが `7k - 1` の場合だけ選択します。`data_init.lua` の既存の
prototype生成経路をそのまま使用します。追加の長さ別画像や実行時処理は不要です。

## 微調整ポイント

材質は純正鋼鉄チェストを目視参照し、明るい摩耗面と暗い油汚れ・酸化面を
分けています。`material()` 内のラベル付きノードで、粗い汚れ、方向性のある
擦り傷、細かな凹凸、粗さ／金属度のむら、継ぎ目のAOを調整できます。
テクスチャはオブジェクト座標なので、横・縦のレンダーでも部品表面に追従します。
外部テクスチャや純正画像の複製は使用していません。

照明は弱めの環境光と幅広い反射用エリアライトを組み合わせています。
本体は96サンプル、デノイズなしで出力し、細かな表面模様を残します。
`material-comparison.png` に材質変更前後の比較を保存しています。

- 天板の明度・金属感とリブの間隔。ゲーム倍率では細かすぎる模様が潰れます。
- ローラー径・開口部の暗さ・黄黒帯の面積。
- J制御塔の高さと端部の太さ。1タイルの地上幅は維持してください。
- 影の方向・Luaの影不透明度。形状変更時は影も更新してください。
- 画像寸法を変更した場合は `scripts/train_loading_segments.lua` も合わせて更新します。

Factorioで確認する項目: 貨車横の6／13／20／83マス、縦向き、J接続部、
複数設備の並設、夜間、回路コネクターとの重なり、通常長5／7／12／14、
無限チェスト版、既存セーブのロード・分割・再結合。

## 実施した検証

- Blender 5.2.1 LTSでモデル保存・本体と影の全16画像出力。
- Lua構文、require先、328通り（長さ2〜83×両方向×通常／無限）の
  切り替え・配置・画像参照と、対象外の従来レイヤー維持。
- 全素材の寸法・透過余白、6／13／20／83のLuaレイヤー合成、比較画像の目視。
- Factorio 2.0.77の分離環境でデータ読み込みと新規セーブ作成に成功。
  DLC有効環境とベースゲームのみの両方で実施。
- グラフィック変更はデータステージのみ。実行時処理・永続状態・prototype名は変更なし。
